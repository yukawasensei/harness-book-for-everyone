# 核心术语

## Model

根据输入上下文预测并生成 token 的模型。模型本身不会直接读取文件或执行命令。

## Tool

提供给模型的函数说明。模型可以请求调用工具，但真正执行由 Harness 完成。

## Agent loop

模型输出工具调用，Harness 执行并把结果放回上下文，模型再继续判断，直到返回最终答案或触发终止条件。

## Harness

围绕模型的工程外壳，包括 system prompt、工具、循环、状态、权限、超时、重试、上下文管理、日志、评测和界面。

## SFT

Supervised Fine-Tuning，用输入与理想输出样本训练模型行为。

## LoRA / QLoRA

LoRA 只训练少量适配参数；QLoRA 以低比特加载底模来节省训练显存。

## Baseline

改动之前的可重复评测结果。没有 baseline，就无法判断 Prompt、Harness 或微调是否真的改善了模型。

## 工序 / Stage

织影将短片创作拆解为单向推进的独立环节（故事 → 剧本 → 设定集 → 分镜板）。每道工序拥有独立的运行状态、专属工具白名单与产物契约，前一道工序经人工审阅采用后方可解锁下一道。

## 采用 / Adopt

人工审阅决定之一。对满意的草稿版本签字确认，将其确立为当前工序的采用版本（adopted），并解锁下游工序或作为下游生成的依赖依据。

## 丢弃 / Discard

人工审阅决定之一。将不满意的草稿标记为丢弃（discarded）。被丢弃的版本保留在历史记录中供复盘查阅，但不能被后续工序引用或直接采用。

## 要求修改 / Request changes

人工审阅决定之一。针对当前候选版本填写修改意见，系统将原稿与批注一并注入新运行以生成新版本，保留原版本历史而不做原地覆盖。

## 设定集 / Bible

短片世界观与实体基准档案工序。按角色（characters）、场景（locations）、道具（props）归档固定外观描写与出场场次（`appears_in`），作为分镜板镜头引用的实体白名单。

## 分镜板 / Board

短片制作前期的最终交付物工序。按场次组织各镜头的景别、运镜、画面主体、动作对白与预估时长，并包含程序自动拼装生成的完整画面提示词（prompt）。

## 逐场提交 / Scene-by-scene submission

长剧本与分镜板的分段受限生成机制。模型通过专属工具逐场（`write_scene` / `write_scene_shots`）写入暂存区，单场结构校验通过后才允许汇总落盘，避免超长上下文一次性输出引发格式崩溃或内容遗忘。

## 覆盖检查 / Coverage check

设定集交稿时的第一道结构硬闸门。由程序核对已采用剧本中的台词角色（含别名）与每场地点是否建档且 `appears_in` 完整；关键道具是否遗漏仍需人审。未过检则拒绝交稿，不生成残缺版本。

## 引用检查 / Reference check

分镜板提交镜头时的第二道结构硬闸门。每镜的角色、场景与道具编号须在设定集中存在；角色与地点的 `appears_in` 须包含当前场次（道具只查编号、不硬查出场场次）；镜头描写不得提及本镜未引用的实体。

## 固定外观注入 / Appearance injection

分镜板提示词的双色拼装机制。模型仅负责创作镜头的构图、动作、光影与情绪描写（蓝色），角色、场景与道具的固定外观描述由程序从已采用的设定集按编号原样代入（绿色），保证跨镜头外观文字一致。

## 重新拼装 / Reassemble

分镜板的零模型调用更新机制。当设定集仅微调了固定外观描写，且故事与剧本未变动时，程序直接复用已有分镜板的镜头描写，并将最新外观注入生成新版本，模型调用次数为 0。

## 待更新 / Stale

依赖失效预警状态。当上游工序切换或采用了新版本时，下游各工序沿依赖链自动标记为“待更新”（stale），提醒用户下游依据已过时，但已有历史版本内容保持只读完整、不自动修改。

## 来源追踪 / Provenance

版本的上游来源记录机制。每个产物版本在生成落盘时显式记录其依赖的上游工序采用版本编号（`based_on`），确保版本关系清晰可溯，支持精准判断变更影响与重新拼装条件。

## 结构评测 / Structural eval

面向四道工序的自动化契约验收流程。通过固定上游案例独立评测各工序的 Schema 契约、单场规则与交叉引用闸门，统计通过率、完成率、工具拒绝数与容错解码次数，为迭代提供可复现的质量底线。

## 人工评分 / Human rubric

面向创作文本审美与质感的五档锚点评分体系。按工序选用故事吸引力与结构、角色辨识度、镜头可拍性与提示词可用性等维度，对各版本独立打分并持久化留存，与机器结构评测解耦。
